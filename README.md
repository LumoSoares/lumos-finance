# LumoS Finance 1.05

Versão baseada no projeto 1.04 com os ajustes solicitados no dashboard, saúde financeira, investimentos, custos fixos e configurações.

## Publicação
Extraia os arquivos e envie todo o conteúdo para a raiz do repositório GitHub Pages, substituindo os arquivos anteriores. Renomeie `sw-v1.05.js` para `sw.js` e `manifest-v1.05.webmanifest` para `manifest.webmanifest` se necessário.

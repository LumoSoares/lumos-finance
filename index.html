Automação real via WhatsApp

Este arquivo funciona totalmente local e, por segurança, não guarda tokens de API. Recebimento automático de mensagens exige um servidor HTTPS, webhook e integração oficial com o WhatsApp Business Platform. Nesta versão, você cola a mensagem e o sistema prepara o lançamento para confirmação.

  3. Entre e importe o backup.
  4. Para sincronização automática entre dispositivos, hospede a aplicação com banco de dados e autenticação.
